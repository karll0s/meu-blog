
# Simples Nerd

Um espaço pessoal para compartilhar ideias, experiências e descobertas sobre Linux, tecnologia e o universo nerd.

## Sobre

O Simples Nerd é meu blog pessoal, criado para registrar aprendizados, compartilhar conhecimentos e escrever sobre assuntos que despertam minha curiosidade.

Aqui você encontrará conteúdos sobre:

- 🐧 Linux e distribuições.
- 💻 Tecnologia e software livre.
- 🛠️ Experimentos, ferramentas e tutoriais.
- 🧠 Curiosidades e descobertas.
- 🎮 Outros assuntos do universo nerd.

## Tecnologias

- [Hugo](https://gohugo.io/) — gerador de sites estáticos.
- [PaperMod](https://github.com/adityatelange/hugo-PaperMod) — tema utilizado.
- Markdown — criação dos artigos.
- GitHub Pages — publicação do site.

## Executar localmente

1. Instale o [Hugo](https://gohugo.io/installation/).

2. Clone o repositório:

   ```bash
   git clone https://github.com/karll0s/meu-blog.git
   ```

3. Entre na pasta:

   ```bash
   cd meu-blog
   ```

4. Inicie o servidor local:

   ```bash
   hugo server -D
   ```

5. Acesse `http://localhost:1313`.
